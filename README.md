# ServiceNow Incident Management – Client Script & UI Policy

## Project Overview

This project demonstrates customization of the **ServiceNow Incident Management** module using **Client Script** and **UI Policy**.

The purpose of this project is to improve the Incident form by implementing client-side behavior and dynamic field control.

## Technologies Used

- ServiceNow
- Client Script
- UI Policy
- Incident Management
- JavaScript

## Features

### Client Script
- Implements client-side logic on the Incident form.
- Controls field behavior based on user actions or field values.
- Provides dynamic form functionality.

### UI Policy
- Dynamically controls form fields.
- Can make fields mandatory, visible, or read-only based on conditions.
- Improves the user experience while creating or updating incidents.
